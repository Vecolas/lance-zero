# Matriz de páginas LanceZero

| Página | Foco principal | Elemento dominante | Ação principal |
|---|---|---|---|
| Landing | proposta de valor | hero + visual de produto | começar |
| Hoje | plano diário | lista de atividades | abrir qualquer card |
| Treino | escolher modalidade | categorias de treino | entrar numa modalidade |
| Aprender skill | ensino | tabuleiro + explicação | avançar etapa |
| Praticar | execução | tabuleiro | responder |
| Revisar | retrieval | tabuleiro | responder antes de revelar |
| Aberturas | biblioteca | mini-tabuleiros | abrir abertura |
| Abertura detalhe | repertório | tabuleiro + comentário | Aprender / Treinar |
| Finais | biblioteca | mini-tabuleiros | abrir tema |
| Final detalhe | princípio/técnica | tabuleiro + raciocínio | Aprender / Praticar |
| Cálculo | processo | tabuleiro + candidatos | registrar linha |
| Game Review | compreender erros | timeline + tabuleiro | revisar momento |
| Progresso | evolução | skills e tendências | entender prioridade |
| Perfil | identidade | formulário simples | salvar |
| Segurança | conta | controles Clerk | gerenciar conta |

## Invariante

Cada página deve possuir:
- um H1 inequívoco;
- uma frase curta de contexto quando necessário;
- uma ação primária ou objetivo principal;
- estados loading/error/empty quando aplicável;
- layout mobile definido explicitamente.
