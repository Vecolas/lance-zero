# Content Hierarchy

## Page header anatomy

```text
breadcrumb (optional)
H1
short supporting description
secondary metadata/actions
```

Do not put three competing headline-sized texts in one region.

## Heading semantics

Typical:
```text
H1 page
  H2 major region
    H3 card/subregion title
```

Do not select heading level based on visual size.

## Labels

Use nouns for sections:
- Plano de hoje
- Variações
- Erros comuns
- Progresso

Use verbs for actions:
- Aprender
- Treinar
- Revisar
- Continuar
- Salvar

## Explanations

For chess teaching:
- headline = idea;
- first sentence = decision/reason;
- optional detail = deeper explanation.

Do not put engine data before the human explanation.

## Text length stress rule

Design every component so that:
- title can wrap to 2 lines;
- description can naturally become 3–4 lines;
- Portuguese localization does not overlap icons/status;
- text zoom does not cover nearby controls.
