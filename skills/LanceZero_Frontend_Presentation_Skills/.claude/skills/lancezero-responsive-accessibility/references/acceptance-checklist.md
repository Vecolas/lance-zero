# Accessibility Acceptance Checklist

## Structure
- one main
- one clear H1
- logical headings
- labelled repeated nav landmarks

## Keyboard
- all controls reachable
- focus visible
- no focus trap outside modal behavior
- card interactions make semantic sense

## Responsive
- 320 CSS px ordinary content reflows
- 360 px phone usable
- 768-ish tablet checked
- wide desktop checked
- no unintended body horizontal scroll

## Text
- 200% resize checked
- long Portuguese title checked
- descriptions wrap
- no fixed-height clipping

## Color
- normal text 4.5:1
- large text when applicable 3:1
- controls/status not color-only

## Touch
- important controls comfortably tappable
- minimum target/spacing rule satisfied

## Chess
- board instructions have textual equivalent
- move/status announced or exposed semantically
- orientation not ambiguous
